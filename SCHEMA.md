# Meal Delivery App Database Schema

## Tables

### 1. `users`
Stores all application users including Customers, Admins, and Delivery staff.
- `id`: UUID (Primary Key)
- `name`: VARCHAR(255)
- `phone`: VARCHAR(20) (Unique)
- `email`: VARCHAR(255) (Unique, required for Admins)
- `password_hash`: TEXT (For Admins)
- `role`: ENUM ('customer', 'admin', 'delivery')
- `address`: TEXT (For Customers)
- `preferred_meal`: ENUM ('veg', 'non-veg')
- `created_at`: TIMESTAMP

### 2. `meal_plans`
Stores available subscription options created by Admin.
- `id`: UUID (Primary Key)
- `name`: VARCHAR(100)
- `price`: DECIMAL(10, 2)
- `meals_count`: INTEGER
- `meal_type`: ENUM ('veg', 'non-veg', 'both')
- `description`: TEXT
- `is_active`: BOOLEAN
- `created_at`: TIMESTAMP

### 3. `subscriptions`
Links customers to meal plans and tracks active status.
- `id`: UUID (Primary Key)
- `customer_id`: UUID (Foreign Key -> users.id)
- `plan_id`: UUID (Foreign Key -> meal_plans.id)
- `status`: ENUM ('active', 'paused', 'expired', 'cancelled')
- `start_date`: DATE
- `end_date`: DATE
- `remaining_meals`: INTEGER
- `pause_start_date`: DATE (Nullable)
- `pause_resume_date`: DATE (Nullable)
- `created_at`: TIMESTAMP

### 4. `deliveries`
Individual daily delivery records generated by the system.
- `id`: UUID (Primary Key)
- `subscription_id`: UUID (Foreign Key -> subscriptions.id)
- `customer_id`: UUID (Foreign Key -> users.id)
- `delivery_boy_id`: UUID (Foreign Key -> users.id, Nullable)
- `delivery_date`: DATE
- `meal_type`: ENUM ('veg', 'non-veg')
- `status`: ENUM ('pending', 'out_for_delivery', 'delivered', 'failed')
- `failed_reason`: TEXT (Nullable)
- `delivered_at`: TIMESTAMP (Nullable)
- `created_at`: TIMESTAMP

### 5. `invoices`
Billing records generated monthly.
- `id`: UUID (Primary Key)
- `customer_id`: UUID (Foreign Key -> users.id)
- `subscription_id`: UUID (Foreign Key -> subscriptions.id)
- `amount`: DECIMAL(10, 2)
- `status`: ENUM ('unpaid', 'paid')
- `billing_period_start`: DATE
- `billing_period_end`: DATE
- `due_date`: DATE
- `created_at`: TIMESTAMP
